Start with `START_HERE.md`.

For product/reference docs, read in this order:
1. `docs/PRD.md`

**Diary cover → Capture Desk → Weave → Art Direction → Interactive Memory Spread → Archive**

Core thesis:
> **Automate the curation, not the authorship.**
