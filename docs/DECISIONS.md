# Memory Atlas — Decision Log

This file records locked product decisions. Append new decisions; do not silently overwrite old ones.

## D-001 — Default landing experience
**Decision:** After the opening diary animation, the product lands on the Capture Desk, not the Calendar.  
**Reason:** Starting a memory should require less navigation than revisiting old memories.  
**Status:** LOCKED

## D-002 — Calendar role
**Decision:** Calendar/Archive is a secondary memory-retrieval surface.  
**Reason:** It is valuable for revisiting memories but should not create friction at entry.  
**Status:** LOCKED

## D-003 — No upfront style configuration
**Decision:** User does not choose palette/template/art style before sharing fragments.  
**Reason:** The system should first understand the memory, then recommend an art direction.  
**Status:** LOCKED

## D-004 — Preserve original evidence
**Decision:** Original photos, voice, and user text remain stored and traceable.  
**Reason:** The final work must still feel like the user's memory.  
**Status:** LOCKED

## D-005 — Full spread is not image-generated
**Decision:** The complete memoir page is deterministically composed from sources + bounded generated assets.  
**Reason:** Needed for text accuracy, interactivity, source fidelity, and provenance.  
**Status:** LOCKED

## D-006 — Art skills are specialized tools
**Decision:** Tape/doodle/zine capabilities operate on selected elements, not the full page.  
**Reason:** Mixing unconstrained independent styles creates incoherent output.  
**Status:** LOCKED

## D-007 — Timeline is optional
**Decision:** A timeline is rendered only when chronology materially improves the story.  
**Reason:** Many memoir entries are thematic rather than temporal.  
**Status:** LOCKED

## D-008 — Weaving includes selection
**Decision:** Weaving must include moment grouping, redundancy removal, story selection, narrative roles, art direction, and preservation decisions.  
**Reason:** The core product value is curation, not only visual generation.  
**Status:** LOCKED

## D-009 — Product thesis
**Decision:** "Automate the curation, not the authorship."  
**Reason:** This resolves the tension between using AI for convenience and preserving human ownership of memory.  
**Status:** LOCKED
